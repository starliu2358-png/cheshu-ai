# V1.0 已知问题

1. **配置对应关系偶发误读**：第一轮真实验收 M5 正确给出 18 英寸续航，但误称长续航后驱版 19 英寸对应值未标明，资料顺序可确定为 800 公里。后两轮通过不表示完全解决。
2. **引用复核不保证正确**：合理用途解释（如巡航减轻长途负担）可接受，但参数、配置结论和操作步骤必须核查。不能以有引用代替语义审查。
3. **表达质量**：偶有重复前文、暴露 section/source_url、将“当前检索资料未列明”泛化成“官网未列明”。
4. **资料范围**：只覆盖已整理的中国市场 Model 3 材料；软件、年份和市场变化以实际车辆手册为准。四配置展示不是自动全配置检索。
5. **语音兼容**：识别、合成和权限取决浏览器及系统语音包，无法保证所有浏览器可用。
6. **部署限制**：本机单用户 SQLite，无账号隔离或生产认证，不应直接对公网提供服务。慢网络/模型排队可能触发 15 秒降级。
7. **能力边界**：无实时车况、远程控制或通用联网搜索；时间工具不能代表具备实时互联网知识。
8. **可选依赖**：混合检索需下载模型及额外依赖；本版本默认简易 BM25 配置与随附 hybrid 模型验收配置不同。
