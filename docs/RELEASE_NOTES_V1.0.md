# 车书 AI V1.0.0

发布日期：2026-10-18

首个独立车书版本，创建全新历史，原项目保留不动。

## 本版能力

- React + FastAPI 单 Agent；DeepSeek 工具调用、查询改写、受控多轮检索。
- BM25，可选 BGE + FAISS + RRF；手册引用、分段关联和证据复核。
- 连续追问、主动换题、结构化会话状态、SQLite 持久化。
- 重命名、置顶、确认删除；四车型只读展示。
- 语音菜单、默认关闭的自动播放、本机偏好和手动播放。
- 官方停止充电、正常拔枪、异常手动释放前提与警告资料。

## 拆仓范围

移除 Gradio、旧 Cockpit Agent、模拟车辆控制、MCP 演示、旧 CLI 及其专用测试。
保留车书 API、Agent、知识库、检索、评测与回归测试。
包导入名 cockpit_agent 保留，避免无必要的大范围重命名。
